# Antonblast Archipelago
> [!IMPORTANT]
> This is a Work in Progress project! 

## What is Antonblast Archipelago? 
- Its a randomizer made for archipelago so people can play online with their friends or alone, 
- this repository has the code of the apworld for archipelago and the code of the mod so
- Antonblast can work with the archipelago client.

## This version was made with any AI?
- No, all the code was made without AI, you can see the documentation and how the code is written to see that by yourself too!

## How do i play this?
- To see how to setup the apworld and the mod you can check [Setup.](SETUP.md)
- There you will find how to use the mod and the apworld and how to create your YAML!
